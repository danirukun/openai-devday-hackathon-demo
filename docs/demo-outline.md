# Pet Island demo outline

Target 75–85 seconds; maximum 90 seconds. Record only with permission to share each pet and asset. Hide the password, private data, browser bookmarks and credentials. The teammate's venue GLB is optional; call the fallback island a preview.

- **0–12 seconds:** Show the island and say that attendees bring Codex pets into a shared community venue. Enter the shared password before recording.
- **12–30 seconds:** Show a rights-cleared pet from Petdex or a valid ZIP, add a fictional personality and place it on the island. Credit the creator.
- **30–55 seconds:** Show the activity log and select a pet to inspect the real decision context and result. If a genuine printer decision has already occurred, show its dot and shared activity in a second session. Otherwise show an actual greeting or wave and say the printer path is still being verified; never present a simulated print as a live decision.
- **55–70 seconds:** Briefly identify the Decisions API's bounded action choice and Supabase's shared state. Show the full-screen world and a phone view if the footage is clear.
- **70–85 seconds:** Explain one concrete Codex contribution: it helped build the server's decision loop and added isolated tests for the shared printer flow. Mention the venue GLB as upcoming if it is not loaded.

Before publishing, verify all displayed assets and links are shareable, confirm permission for the dot-style figures, and check the public repository and setup steps without an authenticated session.
