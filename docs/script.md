**Recording tips**

- Seed 4–6 pets with very different personalities so the choices look varied.
- Turns are ≥10s apart, so record long and cut, or speed up the gaps 4–8×.
- Turn reduced-motion off so the photo flash shows.
- Set `MESSAGE_MODEL` so speech bubbles appear.
- Keep the password screen off camera.

One check: the README on main still lists pet moods as planned, not implemented. If mood isn't shipped (or isn't visible in the click panel) by recording time, drop "based on each pet's mood" and "its mood" so the video doesn't show something judges can't find in the app.
